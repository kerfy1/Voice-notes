# Voice → Notion бот

Telegram-бот, который принимает голосовое (надиктованное или пересланное), и сохраняет карточку-конспект в **Notion**.

🗣 Голосовое (например пересланный подкаст): расшифрует, потом сделает структурированную выжимку (заметку) в базу **Notion**.

📝 Текст (своя заметка, пересланный пост): структурирует, сделает структурированную выжимку (заметку) в базу **Notion**.

Дополнительно можно указать моменты, которые хочешь выделить для заметки.

Выжимка также доступна в самом чате бота.

Языки транскрипции: **русский, українська**.

---

## Как работает

1. Пришёл voice / audio / video note → скачивается.
2. `ffmpeg` конвертирует в mono mp3 64 kbps (речь ужимается сильно, 30 мин ≈ 14 МБ).
3. Если аудио длиннее `NO_SPLIT_UNDER` (7 мин) — режется на чанки по `CHUNK_SECONDS`
   (5 мин по умолчанию), т.к. у OpenRouter таймаут ~60 сек на аудио-запрос.
4. Каждый чанк последовательно уходит в Whisper, в чате показывается прогресс
   («Расшифровываю: часть 3/6…»). Если один чанк упал — остальные всё равно
   транскрибируются, в тексте будет пометка.
5. Бот показывает превью и три кнопки:
   - ✍️ **Добавить акценты** — ждёт от тебя текст, что подчеркнуть.
   - ⚡ **Обработать как есть** — сразу в Claude.
   - ❌ **Отмена**.
6. Claude через OpenRouter возвращает JSON: `title`, `summary`, `tag`.
7. Создаётся страница в базе Notion:
   - **Свойства** (колонки): `Назва ідеї`, `Суть`, `Дата`, `Тег`.
   - **Тело страницы**: конспект + оригинальная транскрипция.
   - Длинный контент дописывается батчами по 90 блоков (лимит Notion — 100).
8. В чат приходит ссылка на созданную страницу.

## Установка

Требуются:
- **Python 3.10+**
- **ffmpeg** (для конвертации и нарезки аудио):
  - Linux: `sudo apt install ffmpeg`
  - macOS: `brew install ffmpeg`
  - Windows: <https://ffmpeg.org/download.html> и добавить в `PATH`
    (или указать полный путь в `.env`: `FFMPEG_BIN=`, `FFPROBE_BIN=`)

```bash
git clone <твой-репо> && cd notion_voice_bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# → заполнить .env
python bot.py
```

## Настройка ключей

### 1. Telegram
- Пишешь `@BotFather` → `/newbot` → получаешь `TELEGRAM_BOT_TOKEN`.
- Свой Telegram ID узнать у `@userinfobot` (для `ALLOWED_USER_IDS`).

### 2. OpenRouter (Whisper + Claude, один ключ)
- <https://openrouter.ai/keys> → создать ключ → `OPENROUTER_API_KEY`.
- Пополнить баланс в разделе Credits — этот баланс тратится и на Whisper, и на Claude.
- Модели по умолчанию:
  - `OPENROUTER_MODEL=anthropic/claude-sonnet-4.5` — для структурирования.
  - `WHISPER_MODEL=openai/whisper-1` — идентичная модели у OpenAI напрямую,
    качество не пострадает. При желании можно переключить на `openai/whisper-large-v3`
    (свежее и дешевле) или `openai/whisper-large-v3-turbo` (быстрее).
- Полный каталог: <https://openrouter.ai/models>.

### 3. Notion
1. Открой <https://www.notion.so/my-integrations> → **New integration** →
   Internal → скопируй **Internal Integration Secret** в `NOTION_TOKEN`.
2. Открой свою базу «Notes» → `•••` в правом верхнем углу → **Connections** →
   выбери созданную интеграцию (без этого API не увидит базу).
3. `NOTION_DATABASE_ID` — 32 символа из URL базы:
   `https://www.notion.so/workspace/<DATABASE_ID>?v=...`
   (тире можно оставить, можно убрать).

### 4. Проверь колонки в Notion
Бот пишет в колонки:

| Имя (по умолчанию) | Тип в Notion   |
|--------------------|----------------|
| `Назва ідеї`       | **Title**      |
| `Суть`             | **Text**       |
| `Дата`             | **Date**       |
| `Тег`              | **Select**     |

Если у тебя другие имена — поменяй переменные `NOTION_PROP_*` в `.env`.
Тип `Тег` **обязательно Select** (не Multi-select). Новые опции API создаст сам.

## Использование

- `/start` — приветствие.
- Пришли голосовое / аудиофайл / кружочек.
- Нажми одну из трёх кнопок.
- Если выбрал «Добавить акценты» — напиши одним сообщением, что подчеркнуть.
- Получишь ссылку на страницу в Notion.
- `/cancel` — сбросить текущий диалог.

## Примечания

### Длинные аудио (30+ минут)
- Файл автоматически конвертируется в mp3 mono 64 kbps и режется на чанки
  по 5 минут (`CHUNK_SECONDS` в `.env`). Каждый чанк обрабатывается отдельным
  запросом, результаты склеиваются.
- Всё тонко настраивается через `.env`:
  - `CHUNK_SECONDS` — длина чанка (по умолчанию 300 = 5 мин).
  - `NO_SPLIT_UNDER` — порог, ниже которого не режем (по умолчанию 420 = 7 мин).
  - `MAX_AUDIO_SECONDS` — предохранитель, дефолт 2 часа. Хочешь больше —
    подними значение.
- **Ограничение Telegram Bot API**: скачивание файлов через официальный API
  лимитировано **20 МБ**. Голосовые сообщения Telegram (OGG Opus) даже в 60 мин
  весят обычно 5–10 МБ, так что проходят. Но если перешлёшь mp3-подкаст на 60 МБ —
  Telegram не отдаст файл боту. Обход: развернуть свой
  [Telegram Bot API Server](https://github.com/tdlib/telegram-bot-api),
  тогда лимит снимается до 2 ГБ.
- **Время обработки**: `whisper-1` работает ~5× realtime → 30 мин аудио ≈ 6 мин
  транскрипции. С `openai/whisper-large-v3-turbo` (200× realtime) те же 30 мин
  обработаются за ~10 сек, можно увеличить `CHUNK_SECONDS` до 900+.

### Прочее
- Все временные аудио и чанки удаляются сразу после транскрипции.
- Диалог с акцентами хранится в памяти процесса (`context.user_data`).
  После рестарта состояние теряется — для персонального бота это ок.
- Хочешь запускать как сервис — оберни в `systemd` или в Docker
  (в образ обязательно положить `ffmpeg`).
